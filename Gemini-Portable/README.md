# Gemini Portable — Windows 10 x64

Распакуйте весь архив и запустите `Gemini.exe`. Вставьте HTTPS-подписку в открывшееся окно. В дальнейшем достаточно запускать `Gemini.exe`; чтобы заменить профиль, закройте окно Gemini и запустите EXE, удерживая Shift.

Установка, права администратора и PowerShell на рабочем ПК не требуются. Требуется штатный .NET Framework 4.x, право записи в папку и разрешение ИТ на сторонний прокси. Chromium и Xray поставляются в папках `Browser` и `Core`. Не переносите только один EXE. Gemini не меняет системный прокси или маршруты.

Поддерживается первый совместимый профиль VLESS Reality/TLS по TCP (raw) из стандартной HTTPS-подписки (текст или Base64, без HTTP-перенаправлений). Форматы только для HAPP, WebSocket, gRPC и XHTTP не поддерживаются. Папка `GeminiProfile` содержит данные доступа и вход Google; не передавайте её другим.
