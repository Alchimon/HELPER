# Gemini VM для Oracle VirtualBox

Образ Debian amd64 с Chromium, Xray и минимальным графическим меню. На Windows устанавливать браузер и прокси не нужно. Подписка и профиль браузера остаются внутри виртуального диска. Поддерживается стандартная HTTPS-подписка VLESS Reality/TLS по TCP, текст или Base64, без HTTP-перенаправлений. Подписки только для HAPP не поддерживаются.

## Запуск

1. Скачайте ZIP из релиза Gemini VM и распакуйте `Gemini-VM-amd64.vdi` в разрешённую папку для виртуальных машин.
2. В VirtualBox создайте ВМ: **Linux → Debian (64-bit)**, 3072 МБ RAM, 2 CPU, используйте **существующий виртуальный диск** `Gemini-VM-amd64.vdi`. Если VirtualBox предлагает автоматическую установку, пропустите её; ISO не нужен.
3. Оставьте **EFI выключенным** (образ загружается в режиме BIOS), видео **VMSVGA**, сеть **NAT**. Запустите ВМ.
4. В меню выберите **Open Gemini** и вставьте ссылку. Чтобы заменить ссылку, закройте Chromium и выберите **Set subscription**. Gemini идёт через Xray; системный прокси Windows не меняется.

## Передача файлов в Windows

В настройках ВМ добавьте одну разрешённую **общую папку** с именем `Gemini-Exchange` (регистр важен). Укажите целевой каталог Windows, выключите **Только чтение**, чтобы выгружать файлы. Не включайте автомонтирование VirtualBox — образ монтирует папку сам по `/media/sf_Gemini-Exchange` через драйвер `vboxsf` ядра Linux. После добавления папки перезапустите ВМ. Файлы загружаются в гостевую папку `Downloads`: закройте окно Chromium, выберите **Files / Gemini-Exchange** и перенесите нужный файл из `Downloads` в общую папку. Можно открыть два окна Thunar, либо перейти в `/home/gemini/Downloads` через адресную строку. Не выгружайте туда подписку и профиль браузера.

Копирование в общую папку создаёт файлы в Windows. Включайте его только для папки, куда ИТ разрешает запись. Без общей папки файлы остаются внутри виртуального диска. Общий буфер обмена и drag-and-drop не нужны; при необходимости ссылку можно ввести вручную или передать файлом через разрешённую папку и удалить файл после импорта.

## Скриншот и сборка

`kiosk.png` в релизе — кадр, снятый с загрузившейся ВМ в CI (QEMU). Он не доказывает, что конкретная подписка работает или что общая папка доступна на конкретном VirtualBox. Сборка публикует VDI, не OVA: шаг создания ВМ делается один раз, гостевой Linux уже установлен.
