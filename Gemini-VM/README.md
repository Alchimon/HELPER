# Gemini VM для Oracle VirtualBox

Проектируемый формат: готовая ВМ x86-64 в одном OVA, с минимальным Linux, Chromium и Xray. OVA импортируется через **Файл → Импорт конфигураций**. Подписка вводится внутри гостевой ОС; профиль Chromium и данные Xray остаются на виртуальном диске. Рекомендуемая сеть — NAT: параметры прокси Windows не меняются.

## Обмен файлами с Windows

Предпочтительный вариант — одна выделенная общая папка `Gemini-Exchange`, а не общий доступ к домашнему каталогу или диску Windows. Для встроенных общих папок VirtualBox нужны работающие Guest Additions в гостевой ОС. В настройках ВМ откройте **Общие папки → Добавить**, выберите разрешённую папку Windows и задайте имя `Gemini-Exchange`. Включите автомонтирование. Для выгрузки файлов из гостя флажок **Только чтение** должен быть выключен. Типичная точка монтирования в Linux — `/media/sf_Gemini-Exchange`; пользователь киоска должен иметь право доступа (обычно членство в `vboxsf`).

Общая папка — исключение из изоляции: копирование туда создаёт файлы на Windows через VirtualBox. Если запись разрешена только для файлов самого гипервизора, согласуйте отдельную папку с ИТ. Если общей папки недостаточно, не включайте перенос файлов, общий буфер обмена или доступ к дискам Windows без разрешения. Не храните в общей папке профиль браузера или подписку.

**Статус:** готовый OVA ещё не собран. Релиз `Gemini-Portable` — приложение для Windows, не образ VirtualBox.
