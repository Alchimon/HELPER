# Gemini Portable для Windows 10 x64

Портативный браузер для Gemini: `Gemini.exe` запускает комплектные Chromium и Xray, открывает `gemini.google.com` в отдельном окне и использует отдельный профиль. Установка, PowerShell и права администратора на рабочем компьютере не нужны. Программа не меняет системный прокси и сетевые маршруты.

## Скачать и запустить

- [Готовый ZIP для Windows 10 x64](https://github.com/Alchimon/HELPER/releases/tag/gemini-portable-v0.1.0).
- [Резервная загрузка из успешной сборки GitHub Actions](https://github.com/Alchimon/HELPER/actions/runs/44739089077/artifacts/14629009787). Артефакт Actions может потребовать входа и хранится ограниченное время.

Распакуйте **весь архив** в папку с правом записи и запустите `Gemini.exe`. При первом запуске вставьте HTTPS-ссылку подписки прямо в окно приложения. При следующих запусках вводить её повторно не нужно. Чтобы сменить подписку, закройте Gemini и запустите `Gemini.exe`, удерживая Shift.

## Совместимость и ограничения

- Целевая платформа: Windows 10 x64 со штатным .NET Framework 4.x. Архив содержит Chromium и Xray; они не скачиваются при запуске.
- Поддерживается стандартная HTTPS-подписка без перенаправлений: текстовый или Base64-список `vless://`. Выбирается первый совместимый профиль VLESS Reality или TLS по TCP (raw). Форматы только для HAPP, WebSocket, gRPC и XHTTP не поддерживаются.
- HTTPS-запрос для импорта подписки идёт через обычное подключение Windows. Трафик Gemini в отдельном Chromium направляется через локальный Xray без прямого резервного маршрута. Это не заменяет сетевой экран.
- Папка `GeminiProfile` хранит данные доступа выбранного профиля и сеанс Google. Не передавайте её другим и не добавляйте в Git. Автоматического обновления компонентов или подписки нет.
- Сборка проверена на Windows-раннере GitHub Actions. Работа Gemini с конкретной подпиской и на целевом Windows 10 не проверена. На рабочем ПК используйте программу только с разрешения ИТ на сторонний прокси.

## Что хранится в репозитории

| Путь | Назначение |
| --- | --- |
| [`Gemini-Portable/Gemini.cs`](Gemini-Portable/Gemini.cs) | Исходник Windows-лаунчера: импорт, локальный прокси, запуск браузера и завершение Xray. |
| [`Gemini-Portable/README.md`](Gemini-Portable/README.md) | Краткая инструкция, которая входит в ZIP. |
| [`.github/workflows/gemini-portable.yml`](.github/workflows/gemini-portable.yml) | Сборка `Gemini.exe` на Windows и упаковка с закреплёнными версиями Chromium и Xray. |

Исполняемые файлы и ZIP не хранятся в истории Git. ZIP публикуется отдельно, а сборки по коммитам доступны в Actions. Обычная сборка не требует ссылки подписки. Для публикации релиза запустите workflow вручную на ветке проекта и укажите новый тег релиза.
